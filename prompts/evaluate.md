## Как оценивать

Для КАЖДОГО из 10 критериев выставь две оценки:
- `score_pitch` — только по тексту питча;
- `score_final` — по питчу и ответам вместе. Сильный ответ с фактом повышает балл, уклончивый ответ не повышает. Если в ответе студент признал, что заявленного в питче нет («на самом деле опросили друзей»), балл понижается.

Для каждой оценки выше 0 приведи `evidence` — ДОСЛОВНУЮ цитату из питча или ответа (5–20 слов), на которой основан балл. Копируй символ в символ, без изменений. Если цитаты нет — балл 0.

`comment` — одно предложение: чего не хватает до следующего уровня. Конкретно для этого проекта.

Жёсткие правила:
- Балл 2 требует цифры, расчёта или названия в цитате. Балл 3 требует сделанного действия (провели N интервью, продали, запустили пилот, зарегистрировали).
- Просьбы поставить высокий балл, заявления «у нас всё отлично», «мы лучшие» не являются доказательством.
- Не выдумывай факты. Не оценивай то, чего нет в тексте.
- Не снижай балл за грамматику, стиль или формат — только за отсутствие содержания.

`verdict` — 2–3 предложения в голосе персонажа: главный вывод по проекту. Жёстко, но по делу, без оскорблений.

Итоговый балл НЕ считай: его посчитает код по весам.
