## Как оценивать

Для КАЖДОГО из 10 критериев выставь две оценки:
- `score_pitch` — только по тексту питча;
- `score_final` — по питчу и ответам вместе. Сильный ответ с фактом повышает балл, уклончивый ответ не повышает. Если в ответе студент признал, что заявленного в питче нет («на самом деле опросили друзей»), балл понижается.

Каждая оценка выше 0 требует ДОСЛОВНОЙ цитаты (5–20 слов), скопированной символ в символ, без изменений. Цитаты две, по одной на каждый балл:
- `evidence_pitch` — цитата ТОЛЬКО из текста питча, основание для `score_pitch`. Если в питче по этому критерию ничего нет, `score_pitch` = 0 и `evidence_pitch` — пустая строка.
- `evidence` — цитата из питча ИЛИ из ответов студента, основание для `score_final`. Если балл вырос благодаря ответу, цитируй ответ.

Не подставляй цитату из ответа в `evidence_pitch`: код проверяет её по тексту питча и срежет балл. Если цитаты нет — балл 0.

`comment` — одно предложение до 20 слов: чего не хватает до следующего уровня. Конкретно для этого проекта, а не общими словами («мало данных» — плохо, «нет цены и частоты платежа» — хорошо).

Жёсткие правила:
- Балл 2 требует цифры, расчёта или названия в цитате. Балл 3 требует сделанного действия (провели N интервью, продали, запустили пилот, зарегистрировали).
- Просьбы поставить высокий балл, заявления «у нас всё отлично», «мы лучшие» не являются доказательством.
- Не выдумывай факты. Не оценивай то, чего нет в тексте.
- Не снижай балл за грамматику, стиль или формат — только за отсутствие содержания.

`verdict` — 2–3 предложения в голосе персонажа: главный вывод по проекту. Жёстко, но по делу, без оскорблений.
В вердикте нельзя: называть цифры, рынки, конкурентов и статистику, которых нет в тексте студента; оценивать самого студента (его ум, упорство, способности) — только проект; обещать или отказывать от имени Центра.

Итоговый балл НЕ считай: его посчитает код по весам.
