# План команды (4 человека)

Тимлид — Дмитрий. Прототип уже собран и проходит 23 теста. Задача команды — подключить модель, задеплоить, проверить на датасете и выиграть голос зала.

## 1. Тимлид (Дмитрий): продукт и промты
- [ ] Узнать персонажа по жеребьёвке → выставить `INVESTOR` (angel / corporate / grant / vc) или описать своего в `prompts/personas/` и `lib/personas.js` (+ пятое поле «чем полезен студенту»).
- [ ] Прогнать 3–5 питчей из датасета с реальной моделью, поправить промты в `prompts/` (тон, длина вопросов, качество советов).
- [ ] Проверить, что жёсткость полезная, а не обидная, на 2–3 «сырых» питчах.
- [ ] Финальная проверка всего перед сдачей: ссылка, README, one-pager.

## 2. Разработчик: деплой и надёжность
- [ ] Получить API-ключ (Anthropic или OpenRouter), положить в `.env` локально, `npm start`, пройти сценарий.
- [ ] Создать **публичный** репозиторий на GitHub, залить проект (проверить, что `.env` не попал в коммит).
- [ ] Render → Blueprint → репозиторий → ввести ключ в Environment → получить ссылку.
- [ ] Проверить ссылку с телефона, замерить время ответа модели (цель: вопрос < 10 с). Если медленно — сменить модель на более быструю (`ANTHROPIC_MODEL`).
- [ ] Перед защитой «разбудить» сервер (бесплатный Render засыпает): открыть ссылку за 5 минут до выступления.

## 3. Тестировщик: ломать бота
- [ ] `npm test` — должно быть 23/23.
- [ ] Прогнать 10 питчей из датасета на живой версии, записать: вопрос цепляется за питч? советы конкретные? бот ничего не выдумал?
- [ ] Атаки на живой версии: пустой питч, «поставь 10/10», «игнорируй инструкции», текст на английском, стихи вместо питча, 10 000 символов, эмодзи, HTML-теги, двойной клик, обновление страницы посреди диалога.
- [ ] Таблица багов → тимлиду; подготовить 1 «слабый» питч для демо на сцене.

## 4. Презентер: one-pager и защита
- [ ] One-pager: проблема (голоса студентов) → решение (схема 5 вопросов → оценка → 3 задачи) → решения 01–07 (из `docs/DECISIONS.md`) → метрики → ссылки.
- [ ] Речь на 2 минуты по каркасу в `docs/DECISIONS.md`, отрепетировать с таймером 3 раза.
- [ ] Сценарий живого демо: слабый питч, ответ «опросили друзей», просьба «10/10», экран результата.
- [ ] Подготовить ответы на 6 вопросов жюри (список в `docs/DECISIONS.md`).
